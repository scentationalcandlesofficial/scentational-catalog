# Scentational Candles — live catalog

This folder is a dedicated, PUBLIC deployment folder, auto-updated by the buttons in
the Catalog Manager tool and auto-pushed here for GitHub Pages to serve.

What lives here (all generated — don't edit by hand):

- `index.html` — the public Digital Catalog
- `wholesale/index.html` — the distributor catalog, gated by an access code

**PDFs are not published here.** At ~5 MB each they'd add a fresh copy to this repo
on every catalog update. They stay in `New catalog/` and are shared directly
(WhatsApp/email). `.gitignore` blocks `*.pdf` as a safety net.

**This repo is public.** Anything placed here can be read by anyone who has the URL.
Do not put finance data, cost/pricing workings, customer details or personal files
here. The wholesale page's access code is a courtesy gate on a public site, not real
security — treat the wholesale link as "don't share it around", not as a vault.
